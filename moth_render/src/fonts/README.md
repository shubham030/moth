# Fonts

Generated by `tools/fontgen/fontgen.py` from Inter, and compiled into the
firmware. Do not edit the headers by hand — regenerate them:

```
python3 tools/fontgen/fontgen.py Inter.ttf 20 \
    --name moth_font_20 -o moth_render/src/fonts/moth_font_20.h
```

Large faces are subsetted, because a full ASCII set at 48px costs 44 KB of
bitmap against 5 KB for digits and a colon. Pass `--chars` with what you
actually draw.

| face | size | characters | bitmap |
| --- | --- | --- | --- |
| `moth_font_14` | 14px | ASCII | 4.1 KB |
| `moth_font_20` | 20px | ASCII | 7.4 KB |
| `moth_font_48` | 48px | digits, colon, space | 5.2 KB |
| `moth_font_72` | 72px | digits, colon, space | 12.0 KB |

`font_for()` in `text.cpp` picks the largest face at or below the requested
size — bitmap faces are never scaled up, since that blockiness is exactly what
they replaced. Adding a size means generating it and adding it to `kFaces`.
